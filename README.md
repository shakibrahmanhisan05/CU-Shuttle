# CU Shuttle Tracker

CU Shuttle Tracker is now available as a **public beta**.

This early release allows users to try the app, share live locations, and test the core experience before the full production release.

## What you can do

- Share your live location
- View shared locations on the map
- Test the main app experience
- Help us find bugs and improve stability

## Beta Notice

This is an early beta version, so you may experience bugs, temporary issues, or unexpected behavior.

If you find a problem, please report it to the CUCSU team.

Thank you for testing CU Shuttle Tracker.
